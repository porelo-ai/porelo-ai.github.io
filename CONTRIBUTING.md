# Contributing

Changes to porelo-ai.github.io follow the project's guide: how an issue is written, how a change is proposed and
reviewed, and what a commit carries. It is one page for every Porelo repository:
[Contributing to Porelo](https://porelo-ai.github.io/porelo-project/contributing/).

## In this repository

- **Building the site:** as the README's [Building it on your own computer](README.md#building-it-on-your-own-computer)
  says: Python in a virtual environment with the pinned requirements, `build/assemble.py` to collect each repository's
  `doc/`, then `mkdocs build --strict`.
- **The pages themselves live in each repository's `doc/`.** A change to a page is made there; this repository holds
  only how the chapters are put together and published.
